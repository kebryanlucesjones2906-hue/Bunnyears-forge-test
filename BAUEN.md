# Bunny Ears (Forge 1.21.4) – .jar bauen

## Windows (einfach)
1. ZIP komplett entpacken (Rechtsklick > Alle extrahieren).
2. Doppelklick auf JAR-BAUEN.bat und warten (erstes Mal 5-15 Minuten, Internet nötig).
3. Fertige Mod: build\libs\bunnyears-1.0.0.jar
4. Diese .jar in den mods-Ordner von Minecraft 1.21.4 mit Forge 54.1.0 oder neuer legen
   (Ordner öffnen: Windows-Taste + R, dann %appdata%\.minecraft\mods).

## Linux / Mac
JDK 21 installieren, dann: ./gradlew build

In der Mod: Taste B = Hasenohren an/aus (Steuerung > Hasenohren).
